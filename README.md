# Rockbox Playlist Manager (With Spotify Features)

### This is a passion project making playlists for rockbox infintley less terrible! At the moment, i've only tested it on my iPod, but it should work on other devices.


## Features:
- [x] Read Tags from your music library and create .m3u8 files with rockbox paths!
- [x] Interface with the Spotify API to get playlists from there and recreate it!
- [ ] Interface with the Apple Music API
